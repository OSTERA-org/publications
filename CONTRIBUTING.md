# Contributing

This repository only contains approved OSTERA publications and is not used to
discuss, develop, or write documents.

## Taking Part in the Work

OSTERA documents are developed in Working Groups, and organizations and
individuals can participate in those Working Groups by joining OSTERA.

* **Membership**: https://www.ostera.org/membership
* **Current Working Groups**: https://www.ostera.org/working-groups

## Commenting During a Public Review

OSTERA encourages public comment on each draft work item prior to final
approval. 

Public reviews are announced at https://www.ostera.org/public-reviews, and
comments are submitted via the Working Group's GitHub repository or via email
at public-review@ostera.org.

## Reporting an Error in a Published Document

If you find an error in a published document, please report it by either opening
an issue in this repository or by sending an email to secretariat@ostera.org.
Please include the document identifier and version (for example OSTERA TS 1000,
Version 1.0), along with the section, and a description of the problem.
Confirmed errors are corrected through an erratum or a corrigendum, published
alongside the original document.

## Intellectual Property

Anything you submit to OSTERA, including public review comments and error
reports, is a contribution under the OSTERA IPR and Copyright Policy. By
submitting it, you agree to the terms of that policy (Article 3). Do not submit
anything confidential (Article 4). If you know of patents or other IPR that may
cover a document, see [IPR.md](IPR.md).

* IPR and Copyright Policy: https://ostera.org/policies/
